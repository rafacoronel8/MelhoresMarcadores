# Artilheiros

Mostra os melhores goleadores, assistentes, golos + assistências e melhor média de golos por jogo,
com a mesma apresentação animada 9:16 e gravação de vídeo para Reels da app Escalação.

## Como usar (VS Code)
1. Abre esta pasta no VS Code e, no terminal, corre: `node server.js`
2. Abre http://localhost:3000
3. Carrega em "Carregar exemplo" para ver como fica, ou "+ Jogador" para adicionar os teus.
4. Atualiza jogos, golos e assistências na tabela depois de cada jogo. Os rankings mudam logo.
5. Escolhe o separador (Goleadores, Assistentes, Golos + Assist., Média de golos) e carrega em "Apresentar".
   Marca "Gravar vídeo Reels (9:16)" para gravar (Chrome ou Edge no PC).

Os dados ficam em `data/state.json` (com cópia de segurança `.bak`). "Guardar cópia" / "Carregar cópia" fazem backup em ficheiro.
Podes pôr foto normal ou GIF animado (até 4 MB) em cada jogador.
